# insAuto

Instagram과 Threads 콘텐츠 자동화를 위한 Next.js + Spring Boot 모노레포입니다. 웹 화면과 AI 클라이언트가 같은 API를 사용합니다.

사이트에서 계정 연결, 생년월일 기반 개인 운세 미리보기, 사주 콘텐츠 일괄 생성, 초안 작성, 실제 게시를 제공합니다. **실제 게시는 연결된 계정과 내용을 확인하고 `실제 게시`를 실행할 때만 진행합니다.** 기존 예약은 모의 실행 전용이며 `SIMULATED`는 실제 게시 성공이 아닙니다.

## 바로 실행

Node.js 22 이상과 JDK 21이 필요합니다.

```powershell
npm install
# 처음 설치할 때만 복사하세요. 기존 .env에는 암호화 키가 있을 수 있습니다.
Copy-Item .env.example .env
npm run dev
```

- 화면: http://127.0.0.1:3001
- API: http://127.0.0.1:8081
- API 명세: http://127.0.0.1:8081/openapi.yaml
- 종료: 실행한 터미널에서 `Ctrl+C`

루트 실행 명령은 루트 `.env`를 읽습니다. 하위 폴더에서 직접 실행하면 환경 변수를 별도로 전달해야 합니다. 기본 포트 3001/8081은 fatell의 3000/8080과 겹치지 않습니다. DB는 `backend/data/`에 저장됩니다.

## 화면 구성

- **대시보드**: 전체 콘텐츠·실제 게시 완료·작성 중·확인 필요, 한국 시간 기준 최근 7일 등록 추이와 채널별 등록 비율을 표시합니다. 조회수/좋아요 통계는 아직 수집하지 않습니다. 4부작도 콘텐츠 한 개로 집계합니다.
- **콘텐츠 등록**: 대시보드 버튼으로 작성창을 열어 채널과 글을 입력합니다. 개인 운세를 가져오거나 이미지 주소를 추가할 수 있습니다. 저장은 초안 등록이며 실제 게시와 별개입니다.
- **사주 콘텐츠**: 주제와 생성 수를 고르고, 필요할 때 문장 세부 설정을 펼칩니다.
- **계정 연결**: `/connections`에서 연결·해제를 관리합니다. OAuth 완료 후에도 이 페이지로 돌아옵니다.

메뉴는 위의 실제 세 페이지로 이동합니다. 콘텐츠 목록에서 검색·채널·상태 필터를 사용하고, 글을 누르면 전체 내용과 모의 실행 옵션이 열립니다. 활동 내역은 접힌 상태로 제공합니다.
## 계정 연결과 게시

운영자는 [Meta 연결 설정](docs/meta-setup.md)에 따라 앱 ID·시크릿, 공개 HTTPS 주소, 워크스페이스 비밀번호와 토큰 암호화 키를 서버에 설정합니다. 사용자는 사이트의 Instagram·Threads 연결 버튼으로 로그인하고 권한을 허용합니다. 사용자에게 비밀번호나 액세스 토큰을 입력받지 않습니다. 미설정 상태는 연결 화면에서 안내합니다.

1. 사이트에서 각 채널을 연결합니다. Instagram은 프로페셔널 계정이 필요합니다.
2. 대시보드의 `콘텐츠 등록 → 생일로 운세 만들기`에서 양력/음력 생년월일과 선택 사항인 출생시각으로 오늘의 운세를 확인합니다.
3. 채널별 문구를 작성창으로 가져와 검토하고 초안을 저장합니다.
4. 운세 카드는 `운세 카드 JPEG 저장`으로 내려받을 수 있습니다(1080×1350). Instagram에는 외부에서 열리는 HTTPS JPEG 이미지 주소를 입력합니다. 현재 이미지를 공개 URL에 올리는 작업은 수동이며, Threads는 글만 게시할 수 있습니다.
5. 초안의 실제 게시 버튼에서 대상 계정과 내용을 확인합니다. 성공하면 Meta 게시 ID와 확인 가능한 게시 링크를 표시합니다.

출생 입력값은 DB에 저장하지 않고 계산에만 사용하며 게시 문구에도 넣지 않습니다. 사주 기둥은 실제 만세력으로 계산하고, 해석은 출생 일간과 오늘 일진의 관계를 활용한 제한적인 규칙 기반 문구입니다. AI가 생성한 정밀 감정으로 표시하지 않습니다. 한국 표준시, 절기 기준, 출생시각 미상 시 가정을 미리보기에 설명합니다.

계정 토큰은 AES-256-GCM으로 암호화해 저장합니다. 암호화 키를 바꾸거나 분실하면 계정을 다시 연결해야 합니다. 만료된 계정은 재연결하며 자동 토큰 갱신은 아직 없습니다. 연결 해제는 로컬 토큰을 삭제합니다. Meta에서 앱 권한까지 없애려면 해당 서비스 설정에서 해제하세요.

## 사주 콘텐츠 발행하기

`/saju-content`에서 늦게 피는 사주·도화·겉은 차갑고 속은 다정한 사주 등 9개 주제로 4부작을 만듭니다. 양면 진술, 숨긴 감정, 오픈 루프, 선택받은 느낌, 찌르고 안아주기를 각각 선택하고 말투·댓글/저장 유도를 바꿀 수 있습니다. 한 번에 1~12세트를 생성하며, 생성 결과는 저장하기 전까지 브라우저에만 있습니다.

현재 생성기는 직접 작성한 문장을 조합하는 템플릿 방식입니다. 외부 AI 호출이나 개인 명식 분석은 하지 않습니다. 문단별로 수정·복사하고, 원하는 세트만 선택해 일괄 저장하세요. 저장 요청 ID로 중복 생성을 막으며, 중간에 잘못된 항목이 있으면 전체 저장을 취소합니다.

Threads로 저장하면 4개 문단을 하나의 시리즈로 관리하고, 전체 문안과 계정을 확인한 후 첫 글과 답글 3개를 순서대로 게시합니다. 답글 권한을 먼저 확인하고, 각 편의 게시 ID를 즉시 보관합니다. Instagram으로 저장하면 네 문단을 합친 캡션 초안을 만들며, 대시보드에서 초안을 수정해 공개 JPEG 이미지 URL을 추가하고 게시합니다. 두 채널 동시 게시나 예약 실게시 기능은 아닙니다.

`PUBLISH_PARTIAL`은 앞선 편이 공개되었지만 다음 편 준비가 실패한 상태입니다. 게시된 편을 되돌리지 않으며, 남은 편을 자동 재전송하지 않습니다. `PUBLISH_UNKNOWN`이면 확인된 편 외에도 게시물이 존재할 수 있으므로 실제 계정을 확인하세요. 기존 Threads 연결은 새 답글 권한을 허용하도록 다시 연결해야 할 수 있습니다.
## 게시 결과와 중복 방지

게시 시작 전에 초안 버전과 계정 ID를 검사하고 실행 상태를 저장합니다. 동시 클릭과 같은 요청의 재전송을 막습니다. 처리 도중 네트워크가 끊겨 게시 여부가 불분명하면 `PUBLISH_UNKNOWN`으로 남기고 자동 재전송하지 않습니다. 서버 재시작 중 중단된 작업도 확인 필요 상태로 전환합니다. 먼저 실제 계정의 게시 내역을 확인하세요.

`PUBLISH_FAILED`는 게시 준비에 실패해 게시 호출을 보내지 않은 상태입니다. 실패한 게시물의 내용과 원인을 확인한 뒤 새 초안으로 시작할 수 있습니다. 이미 성공한 요청을 다시 보내면 저장된 결과만 반환합니다. 예약 게시(`SCHEDULED`)는 여전히 모의 실행이며 실제 게시와 별개입니다.

## 구조와 명령

```text
insAuto/
├─ frontend/              Next.js 화면, 비공개 워크스페이스 로그인, OAuth 콜백
├─ backend/               Spring API, 사주 계산, 토큰 저장, Meta 게시, 모의 예약
├─ packages/mcp-server/   AI 클라이언트용 MCP stdio 도구
├─ scripts/               통합 실행 명령
├─ docs/                  Meta 설정, AI 연결, 구조 설명
└─ .env.example           서버 환경 변수 예시
```

```powershell
npm run dev:frontend
npm run dev:backend
npm run typecheck
npm test
npm run build
npm run test:backend
npm run test:mcp
```

API는 `Authorization: Bearer <INSAUTO_API_KEY>` 또는 `X-API-Key`를 받습니다. `health`와 API 명세는 공개 정보입니다. 프론트엔드 서버가 API 키를 넣으며 브라우저에 전달하지 않습니다. 공개 HTTPS 주소를 허용하면 워크스페이스 로그인도 필수입니다. **한 명/한 팀이 사용하는 단일 워크스페이스·단일 백엔드용**이며, 불특정 다수의 개별 계정을 분리하는 SaaS는 아닙니다. 외부 공개 시 개발 기본 API 키를 교체하고 백엔드는 외부에 직접 노출하지 마세요.
